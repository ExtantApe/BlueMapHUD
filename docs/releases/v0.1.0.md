The first release of BlueMapHUD: a minimap and coordinates HUD for Paper, drawn from BlueMap's tiles with a small resource pack, plus a fullscreen map. No client mods or shaders. It's an unofficial add-on for BlueMap and isn't affiliated with BlueMap's authors.

**Pre-release.** It has passed its tests on live Paper 26.1.2, 26.2 and 26.3 servers, driven by a protocol bot, but hasn't been seen in a real game client yet. Try it on a test server first.

## Requirements

- Paper 26.1.2, 26.2 or 26.3 (26.1 and newer). It's a Paper plugin, so it won't load on Spigot. Paper 1.21.11 and older aren't supported.
- Java 25.
- BlueMap 5.20 or newer on 26.1.2, 5.22 or newer on 26.2, and 5.24 or newer on 26.3. Only 5.29 was tested.
- Java Edition players. Bedrock players through Geyser get no map.

## Install

1. Put `BlueMapHUD-0.1.0.jar` in `plugins/`, next to BlueMap, and start the server.
2. Players download the plugin's resource pack from port `8164`. Open that port, or host the zip elsewhere with `pack.public-url` (see the README).
3. Settings are in `plugins/BlueMapHUD/config.yml`. Apply changes with `/bmhud reload`.

## What's in it

- A minimap at the top of the screen and a fullscreen map (`/map`, or sneak + F), drawn from BlueMap's own tiles, with players, POI markers, your death point and edge arrows.
- A coordinate line with X, Y, Z, facing and an in-game clock, or coordinates on their own with `/hud mode coords`.
- Four themes: Classic, Desert, Galaxy and High Contrast. The server picks the default, and players choose their own with `/hud theme`. Servers can add their own as JSON files.
- `/hud share` to send your coordinates to people you pick. Sharing follows the server's rules through `CoordinateShareEvent`, players can turn it off, the sender sees who got them, and every share is logged.
- One boss bar at most, hidden while another plugin shows one. While a player stands still, only the clock sends an update, every 5 in-game minutes (about 4 real seconds) by default.
- A failed pack download never kicks: the player plays without the map, admins are warned, and it tries again on a world change.

## Tested, simulated and not tested

Tested on fresh Paper 26.1.2, 26.2 and 26.3 servers with BlueMap 5.29, one at a time, using this release's code:

- The live suite, 331 checks, passed on all three: map accuracy against BlueMap's tiles, icons, the coordinate line, the clock, themes, sharing, hiding rules, one boss bar, updates, pack handling, reloads, the action bar channel and the HTTP source.
- Command back-off from another plugin passed on all three.
- On 26.3: `pack.public-url` and its check (36 checks), BlueMap on SQLite (1024 of 1024 cells), 8 clean BlueMap starts, and 20 moving players for a minute (63 µs per frame, 2.1 KB per update at the 95th percentile, 7.6 ms tick).
- Each version's Minecraft client code loaded the generated pack, and its font code measured all 18,944 glyphs exactly as the plugin expects.
- 48 unit tests, including every theme's contrast over ten backgrounds.

Simulated: the client is a protocol bot speaking 1.21.11 through ViaBackwards, not a real game. Other plugins (vanish, boss bars, permissions, a pack sent the way Magic does, a chat rules plugin filtering shares) were played by a test helper.

Not tested: a real game client, the real Magic plugin, pressing the share dialog's buttons, Bedrock players through Floodgate, MySQL and PostgreSQL storage, and back-off from another plugin's Brigadier commands.

## Known limits

- The map starts at the top centre of the screen, because the server can't see screen sizes. `/hud offset` and `/hud corner` move it.
- A boss bar made with Bukkit's unregistered `createBossBar` can't be detected, so the minimap stays up beside it.
- The pack makes one boss bar colour transparent (pink by default). Pick an unused one with `pack.boss-bar-color` if another plugin uses pink.
- The pack is re-sent once per session if another plugin clears it. Plugins such as Magic that send their pack with Bukkit's old one-pack method should be set to stop doing that; the README explains how.

The README has the full commands, permissions and settings.
